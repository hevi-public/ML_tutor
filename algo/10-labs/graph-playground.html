Prompts worth trying

Draw a cycle and watch topological sort name it. Two-color a square, then pentagon. Give Kruskal a tie and compare with Prim. Build a graph where BFS's hop-count route and Dijkstra's weighted route disagree. Make Bellman-Ford's tripwire fire (directed + a negative loop — set weight, er, the editor keeps weights positive; make the cheapest cycle and reason about what WOULD happen). Break a bipartite graph with one chord. Every one of these is a unit 4–5 theorem you now own.
