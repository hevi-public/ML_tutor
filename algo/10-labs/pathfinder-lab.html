Lab: pathfinding race

Implement shortest-path search on the course's own maze model — the same seeded mazes unit 4 animated. The harness checks your path is valid (adjacent open cells, start to goal) and optimal (matches the reference BFS length), across several seeds. Wrong-by-one path lengths and walked-through-walls both get named specifically.

Before you start BFS and the maze model ({w, h, walls: Set("x,y"), start: [x,y], goal: [x,y]}).
The bug families this catches

Marking seen at visit instead of discovery (duplicates → wrong lengths on some seeds), forgetting the goal can be the start, diagonal moves (adjacency check fails), path reconstruction reversed or missing the start cell, and DFS submitted as BFS (valid path, non-optimal length — the harness distinguishes these two failures precisely because they teach different lessons).
