Lab: build a hash table

No Map, no Object as storage — buckets, a hash function, and collision handling, from parts. The harness feeds it adversarial keys that all collide, because collision handling that never ran isn't collision handling.

Before you start Hash tables — especially chaining and why deletes are the subtle case.
Why the colliding keys

The harness includes keys crafted to share a bucket under reasonable small-table hashing. A table that stores by hash(key) alone overwrites them into each other — the exact bug class behind real-world hash-flooding incidents, where attackers mass-produce collisions to turn O(1) into O(n). Chaining with full-key comparison inside the bucket is the fix you're implementing.
