Cycles and two-coloring: can the graph take sides?

Try to paint every node one of two colors so no edge connects same-colored nodes. Either you succeed — the graph is bipartite, it splits into two clean camps — or the attempt fails in a very specific, very informative way: it hands you an odd-length cycle as a certificate. Win or lose, you learn something structural.

Before you start BFS — two-coloring is BFS carrying one extra bit per node — and DFS's back-edge idea for the cycle half.

The idea

Traverse from any start, painting as you go: the start gets color A, everything it discovers gets color B, everything they discover gets A — always the opposite of your discoverer. Along the way, check every edge. If an edge ever connects two same-colored nodes, the paint job is impossible — and not just for your traversal: no two-coloring can exist, because that same-color edge closes a cycle of odd length, and around an odd cycle the colors must alternate A,B,A,B,…,A — leaving the last edge connecting A to A no matter what.

So one linear-time traversal delivers a perfect dichotomy: bipartite ⇔ no odd cycle, and whichever side is true, you hold the evidence — either the completed coloring or the offending edge. Answers-with-certificates is a theme that peaks in unit 11's P vs NP.

Where you'll meet this

Bipartite structure is the shape of assignment: workers/jobs, students/projects, ads/slots, GPUs/training jobs — unit 5's matching page runs on it. Two-coloring is conflict scheduling in miniature ("can these tasks split across two machines with no conflicting pair together?"). Cycle detection is the load-bearing half elsewhere: deadlock detectors on waits-for graphs, "circular import" errors, circular foreign keys, dependency cycles in agent pipelines — all the same back-edge test, and the reason your bundler can warn you before production does.

The details (open as much as you like)

Show the proof — odd cycle ⇔ not two-colorable

(⇒) Suppose the graph contains a cycle of odd length k and, for contradiction, a valid two-coloring. Walk the cycle: colors must alternate, so nodes at even positions match the start's color and odd positions the other. After k steps you return to the start — but k is odd, so the walk assigns the start the opposite of its own color. Contradiction. (⇐) Suppose the traversal's paint job fails: an edge {u, v} with u, v the same color. Both got their colors along discovery paths from the same traversal root, and same color means those path lengths have the same parity. The root-to-u path, the edge {u, v}, and the v-to-root path close a walk of odd total length — and any odd closed walk contains an odd simple cycle inside it. So failure certifies an odd cycle. ∎

In plain English: even loops let two colors chase each other around cleanly; odd loops force a color to bite its own tail.

Cycle detection per graph flavor — the practical cheat sheet

Undirected: any edge to an already-seen node that isn't your direct discoverer closes a cycle — BFS or DFS both spot it. A connected undirected graph with no cycle has exactly |V|−1 edges: that's a tree, the boundary case (MSTs live there). Directed: seen-before isn't enough — a diamond a→b→d, a→c→d revisits d with no cycle. You need DFS's "still on my current path" test (the back edge), or Kahn's stall. Using the undirected test on a directed graph is a classic false-positive bug in homemade dependency checkers.

The code

// The demo's exact code (assets/js/algo/graphs.js), events elided:
function twoColor(graph) {
  const adj = adjacency(graph);
  const color = new Map();
  for (const { id } of graph.nodes) {          // every component gets painted
    if (color.has(id)) continue;
    color.set(id, 0);
    const queue = [id];
    while (queue.length) {
      const u = queue.shift();
      for (const { to } of adj.get(u)) {
        if (!color.has(to)) {
          color.set(to, 1 - color.get(u));     // opposite of discoverer
          queue.push(to);
        } else if (color.get(to) === color.get(u)) {
          return { bipartite: false, witness: [u, to] };  // odd cycle found
        }
      }
    }
  }
  return { bipartite: true, color };
}
