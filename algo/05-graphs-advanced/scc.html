Strongly connected components: find the knots

In a directed graph, "connected" is a one-way claim. The two-way version — u reaches v and v reaches u — carves the graph into its knots of mutual reachability. Collapse each knot to a dot and something wonderful happens: what remains is always a DAG, and every DAG-only tool from unit 4 suddenly applies to any directed graph.

Before you start DFS — specifically the layered entry/exit-times material; Tarjan's algorithm is that idea sharpened into a tool — and weak vs strong connectivity.

The idea

Mutual reachability is an equivalence, so it partitions the nodes: each class is a strongly connected component. Inside an SCC, everyone reaches everyone (every node sits on a cycle with every other); between SCCs, travel is one-way only — if you could get back, the two components would have been one. That's why the condensation (one meta-node per SCC) is always a DAG, and it's the fact that makes SCCs an engineering tool: it splits any messy directed system into "the cyclic knots" and "the acyclic skeleton between them".

Tarjan's algorithm finds all SCCs in one DFS pass. Each node gets an index (DFS arrival order) and a lowlink — the smallest index reachable from its subtree using at most one back-edge onto the current stack. Nodes go onto a stack as visited; when a node finishes with lowlink === index, it learned it can't reach anything older than itself: it is the root of an SCC, and everything above it on the stack — its whole knot — pops off together.

Where you'll meet this

Architecture analysis is the daily one: run SCC on your service-call or module-import graph, and every component bigger than one node is a circular-dependency knot — the SCC is the exact set to refactor, and the condensation is the clean layering you're refactoring toward (compilers use it to order codegen; bundlers to break import cycles). Beyond that: deadlock analysis (an SCC in the waits-for graph), 2-SAT solvers (satisfiable ⇔ no variable shares an SCC with its negation), and the web's structure (the famous "bow-tie" giant SCC). Model checkers hunt SCCs to find loops a system can get stuck in.

The details (open as much as you like)

Lowlink, slowly

Think of index as your arrival timestamp and lowlink as "the oldest ancestor I can sneak back to". Three update rules: exploring a fresh neighbor — inherit its lowlink after it finishes (its escape routes are yours); meeting an already-visited node still on the stack — take its index (a direct back-door to an open ancestor); meeting a node no longer on the stack — ignore it (its component already sealed; no route back). A node finishing with lowlink = own index has no back-door at all: everything above it on the stack could only escape through it, so they form one complete knot. One DFS, O(|V| + |E|), every SCC in reverse topological order — Tarjan's 1972 paper remains the standard.

Kosaraju's two-pass alternative

Easier to prove, easier to remember: (1) DFS the graph, recording finish order. (2) Reverse every edge. (3) DFS the reversed graph in decreasing finish order; each launch's reach is exactly one SCC. Why: reversing edges preserves SCCs (cycles survive reversal) but flips the one-way travel between them, and the finish-order trick ensures each launch starts in a "source" component of the reversed condensation, so it can't leak into unfinished ones. Two full passes and a reversed copy of the graph — more machinery at runtime, less in your head. Both are linear; Tarjan's is what you ship, Kosaraju's is how you explain SCCs to someone in an elevator.

The code

// The demo's exact code (assets/js/algo/graphs.js), events elided:
function strongConnect(u) {
  index.set(u, counter); low.set(u, counter); counter++;
  stack.push(u); onStack.add(u);
  for (const { to } of adj.get(u)) {
    if (!index.has(to)) {
      strongConnect(to);                             // fresh: recurse, then
      low.set(u, Math.min(low.get(u), low.get(to))); // inherit its escape
    } else if (onStack.has(to)) {
      low.set(u, Math.min(low.get(u), index.get(to))); // back-door to ancestor
    }                                                // off-stack: sealed, ignore
  }
  if (low.get(u) === index.get(u)) {                 // no escape above me:
    const scc = [];                                  // I root a component
    for (;;) {
      const w = stack.pop(); onStack.delete(w);
      scc.push(w);
      if (w === u) break;                            // the whole knot pops
    }
    components.push(scc);
  }
}
