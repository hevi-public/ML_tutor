Dijkstra: shortest paths when edges have prices

BFS answered "fewest hops". But hops lie: a three-hop route over fast links beats one slow hop. Give each edge a cost, and shortest paths need the most famous algorithm in this course — BFS with its queue promoted to a priority queue, plus one greedy commitment that's only legal because prices can't be negative.

Before you start BFS and unit 2's heap — Dijkstra is the reason priority queues were in the toolbox.

The idea

Keep a best-known price d(v) for every node: 0 for the start, ∞ elsewhere. Repeat two moves. Settle: take the unsettled node with the cheapest best-known price and declare that price final. Relax: for each of its edges, check whether going through it beats a neighbor's current best — d(u) + w(u,v) < d(v) — and if so, improve d(v) and remember u as v's parent.

The bold part is settling. The algorithm commits to the cheapest frontier node without looking at the rest of the graph — pure greed. It's legal for one reason: with non-negative weights, any other route to that node would have to leave through a frontier node that's already pricier, and prices only rise from there. Cheapest-so-far is therefore cheapest-forever. (Let one weight go negative and this argument dies — that failure is the next page.)

Where you'll meet this

The literal one: road navigation (weights = travel time) and network routing — link-state protocols like OSPF run Dijkstra at every router. The structural one is everywhere costs accumulate along paths: cheapest currency-conversion chains, minimum-latency service routing, weighted job pipelines, "cost to reach this state" in planning. And in unit 9's vector search, HNSW's greedy descent is Dijkstra's settle-the-cheapest instinct applied to similarity space — the frontier ordered by distance to the query.

The details (open as much as you like)

The priority queue is the complexity

Every step needs "cheapest unsettled node" — an extract-min, plus a decrease-key each time a price improves. This demo's code scans the whole dist map (transparent to read, O(|V|²) overall — genuinely fine at teaching scale, and honestly, for small dense graphs in practice). Production swaps in unit 2's binary heap: O((|V| + |E|) \log |V|). In plain English: near-linear with a log factor as the price of keeping the frontier sorted. Same algorithm, one data structure swapped, a complexity class apart — the whole point of unit 2 in one sentence.

Show the proof — why settling is safe

Claim: when u is settled, d(u) = δ(s, u), the true shortest distance. Induction on settle order. The start settles at 0 — correct. Suppose all earlier-settled nodes have correct final prices, and u is now the cheapest unsettled node. Any path P from s to u must, at some point, first step outside the settled set — say at edge (x, y) with x settled, y not. The prefix of P up to y already costs at least d(y): x's relaxation offered y the price d(x) + w(x, y), and d(y) can only be that or better. And d(y) ≥ d(u) because u was chosen as the cheapest. With non-negative weights, the rest of P from y onward can only add cost, so cost(P) ≥ d(y) ≥ d(u). Every path costs at least d(u): settling is safe. ∎

Spot the exact line where non-negativity earned its keep: "the rest of P can only add cost". A −5 edge later in P breaks that sentence and the whole proof with it.

The code

// The demo's exact code (assets/js/algo/graphs.js), events elided:
function dijkstra(graph, start) {
  const adj = adjacency(graph);
  const dist = new Map(graph.nodes.map((n) => [n.id, Infinity]));
  const parent = new Map();
  const settled = new Set();
  dist.set(start, 0);
  for (;;) {
    let u = null, best = Infinity;              // extract-min (heap in prod)
    for (const [id, d] of dist) {
      if (!settled.has(id) && d < best) { best = d; u = id; }
    }
    if (u === null) break;                      // rest unreachable
    settled.add(u);                             // the greedy commitment
    for (const { to, w } of adj.get(u)) {
      const alt = best + w;                     // price via u
      if (alt < dist.get(to)) {
        dist.set(to, alt);                      // relax: better route found
        parent.set(to, u);
      }
    }
  }
  return { dist, parent };                      // parents = shortest-path tree
}
