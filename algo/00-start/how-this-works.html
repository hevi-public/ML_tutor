How this tutor works

A course in the computer science you skipped — built for someone who ships software for a living and doesn't need to be taught what a for-loop is. Five minutes here explains the machinery you'll use on every page.

Who this is for You write code professionally. Maybe you started a CS degree and left before the algorithms years; maybe you never went. Either way: this course assumes programming fluency and zero theory — Big-O, proofs and graph theory are all built from scratch, in plain English first.

Every algorithm runs, and you hold the controls

The core promise of this site: nothing is explained that can't also be watched. Every algorithm is implemented once, as real JavaScript, and that single implementation is the code printed on the page, the code that draws the animation, and the code the practice labs grade you against. How a page is laid out

Every topic page follows the same flow, so you always know where you are:

The idea (plain words, no notation) → Watch it run (the demo above, for that topic) → Where you'll meet this (the box below) → The details (collapsible layers) → The code → Check your understanding (a short quiz) → Where this goes next.

Where you'll meet this

This green-edged box appears on every page, and it's half the reason this course exists: each topic is tied to the production systems you already work with — caches, build tools, databases, and the LLM-era stack (vector search, knowledge graphs, agent pipelines) where thirty-year-old algorithms suddenly run the show. Unit 9 is entirely made of these.

The layers: proofs are on tap, never forced

The idea in words — always open, always enough

The top layer of every "details" section is plain English, and the course is complete if you only ever read this layer.

Show the math — open when you want precision

Formal definitions, typeset properly. Every symbol is clickable — name, pronunciation, what it stands for right here — and no symbol is ever used before the site has introduced it. The notation reference holds them all.

Show the proof — open when you want certainty

Correctness arguments and lower bounds live at this depth. House rule: proofs are privileges, not prerequisites. No quiz outside the expert unit ever requires one.

Quizzes, progress and flashcards

Each page ends with a few questions asked in plain words — they test understanding, not vocabulary. Finishing a quiz marks the page complete (the landing page uses this to offer "continue where you left off"), a quiz never blocks you from moving on, and any question you miss quietly becomes a flashcard for later review. Everything is stored in your browser's localStorage; nothing leaves your machine.
