Recovery drill

Four scenarios, each one a mess someone has had at 6pm on a Friday. No new material — just the units so far, under time pressure.

Before you start Units 2 and 3. Every drill here is solvable with reset, reflog, fsck, rebase and branch — nothing you haven't already used.

How to use this page

Each drill starts from a broken state. Read the goals, then fix it — hints are there if you want them, but try the first move from memory. If you wreck it further, Reset sandbox puts the mess back exactly as it was, which is the point of practising here rather than at work.

The habit worth building is the first move, not the whole solution. In almost every case it's one of:

git reflogwhere was I before this went wrong?
git statuswhat state does git think it's in?
git log --oneline --all --graphwhat does the history actually look like?
git fsck --unreachable --no-reflogswhat's stranded that nothing names?
