Things worth trying

  • Break something on purpose and recover it without using the hint button.
  • git rebase -i HEAD~4 and use a command you've never used — exec, break, or reordering two lines.
  • Make a commit with plumbing only, then check git fsck --no-reflogs before you move a ref onto it.
  • Look at .git/ in the object explorer while you work: watch MERGE_HEAD and rebase-merge/ appear and vanish.
  • Write a .git/hooks/pre-commit that enforces something you actually want at work.
