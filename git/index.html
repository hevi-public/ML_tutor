Git Tutor

The half of git you never got taught: rewriting history on purpose, the object database underneath, digging through the past, and the collaboration commands that stop you destroying other people's work.

Every exercise runs against a real git repository in your browser — real objects, real hashes, real refs — so you can practise rebase --onto and reset --hard on a repository that doesn't matter. Break it as often as you like; there's a button that puts it back.
