How this reference works Every versioned claim on this site is one record in a single ledger (web/data/changes.json), rendered on the page as a now / was card with the version it landed in and why it changed. The deprecation ledger, the timeline and the migration list are all generated from those same records, so they cannot drift apart. Press / anywhere to search — results cover the pages, the change records (so searching an old API like destroy$ finds what replaced it), and the official docs themselves.
