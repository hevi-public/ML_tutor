Every official page this reference links to, in one filterable list — so "where is the actual documentation for this?" is a search box away rather than a search engine away.

Why these are worth trusting Every URL on this site lives in one file, web/data/links.json, and is referenced by id. npm run check:links walks the whole registry: it confirms each id is actually used, that no page has drifted from the registry, that every URL still resolves, and — for links that point at a specific section — that the anchor still exists. A moved doc is a one-line fix in one file, not a hunt through thirty pages.
Dashed borders A chip with a dashed outline is marked unverified: the URL follows the site's documented pattern but has not been confirmed reachable from the environment this was authored in. Running npm run check:links locally settles them.
