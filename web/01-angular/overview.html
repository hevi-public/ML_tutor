Angular

Modern Angular in one page

If you last wrote Angular before v16, almost every idiom you know has a replacement. Here is the whole arc — what changed, in what order, and which parts you can ignore.

The four shifts that matter
  • NgModules became optional, then unnecessary. Components declare their own imports. Standalone is the default since v19; the standalone: true flag is now redundant.
  • Signals replaced "tell Angular something changed". State that knows who reads it means Angular can update precisely what depends on it, instead of re-checking the tree.
  • Structural directives became template syntax. @if, @for, @switch, @defer and @let are part of the language, not imports.
  • Zone.js became optional. With signals carrying the change information, the library that patched every browser API to guess when to re-render is no longer needed.

What you can still ignore

Not everything new is something you need. Three honest caveats:

You do not have to rewrite working code Decorator inputs, NgModules and *ngIf all still work in v22 and none of them is deprecated. The migrations exist so you can adopt the new forms on your own schedule, not because the old ones are about to break. The rows in what changed marked removed are the only ones with a deadline attached.

RxJS has not been replaced either. Signals took over synchronous state a template reads; RxJS still owns everything that is genuinely a stream over time — debouncing, cancellation, retries, websockets, coordinating several async sources. The two interoperate in both directions. That decision gets its own page: signals or RxJS?

And zoneless is not automatic. It is a provider you opt into, and an application that mutates state outside signals will need work before it behaves. See change detection.

Where to start reading

If you are actively porting a codebase, the order that causes the least churn is: DI (mechanical, low risk) → templates (one schematic, large diff, no behaviour change) → signals (the conceptual one) → zoneless (only once the first three are done).
